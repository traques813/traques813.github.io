Unit 3 expanded the focus beyond file formats to the broader process of locating, verifying, and collecting data from diverse sources. Data quality is inseparable from the credibility of its origin, making fact-checking and source validation a core part of early-stage wrangling (Kahn et al., 2002). Public repositories, academic databases and expert-curated platforms serve as reference points for this evaluation.

The unit covered the main categories of data sources—government portals, research organisations, web services, private datasets and crowdsourced platforms—each carrying different trade-offs in terms of reliability, cost, update frequency and format constraints (Batini & Scannapieco, 2016).

A practical task involved web scraping, using `requests` and `BeautifulSoup` to extract article paragraphs containing the phrase “data scientist”. This demonstrated the typical scraping workflow: requesting a page, parsing HTML, traversing tags, and writing structured output. Unlike APIs, scraping is susceptible to HTML changes, broken layouts and legal/ethical considerations (Mitchell, 2018), making it a technique that requires caution.

APIs were introduced as a more stable alternative for automated data collection, though they bring risks such as rate limits, deprecated endpoints, and potential exposure of tokens.

Overall, Unit 3 emphasised that effective data collection requires understanding source reliability, legal constraints, and the technical limitations of extraction methods—insights that directly informed later stages of cleaning and transformation.

import requests
from bs4 import BeautifulSoup
import json

url = "https://www.coursera.org/articles/what-is-a-data-scientist"
response = requests.get(url)
soup = BeautifulSoup(response.text, "html.parser")

paragraphs = soup.find_all("p")
results = []

for p in paragraphs:
    text = p.get_text(strip=True)
    if "data scientist" in text.lower():
        results.append(text)

with open("data_scientist_results.json", "w", encoding="utf-8") as f:
    json.dump(results, f, ensure_ascii=False, indent=2)

print("Paragraphs found:", len(results))
