Unit 4 focused on the practical aspects of *cleaning and transforming data* before analysis can take place. The UNICEF MICS dataset acted as a realistic example of how raw files often contain inconsistencies, mismatched metadata, or missing documentation. This aligned with common findings in data-wrangling literature, where raw public datasets frequently require extensive preparation before they become analytically useful (Dasu & Johnson, 2003).

A core challenge in this unit was the lack of readable headers. The original dataset included short acronyms, while the scraped header file provided full descriptive labels. As noted by van der Aalst (2016), metadata mismatches are a major cause of ambiguity during early data processing. Following this guidance, the first step involved mapping acronym headers to their readable equivalents using a matching script.

Most acronyms mapped cleanly, but several were absent from the scraped header list. This reflected a real-world issue discussed by Rahm & Do (2000): metadata originating from different countries or collection cycles rarely aligns perfectly. These cases were logged separately for further investigation.

Once readable headers were applied, additional cleaning steps were performed. Placeholder values (“NA”, “N/A” and blanks) were standardised, and initial integrity checks confirmed that no duplicate rows were present. As the literature highlights, standardising missing-value conventions is crucial for preventing silent errors in later analysis (Kandel et al., 2011).

The unit also emphasised initial structural exploration: examining missingness per variable, identifying unusual types, and checking whether numeric fields had been incorrectly parsed as strings. These early inspections align with recommended practices in data profiling, where understanding the structure of the dataset precedes any statistical modelling (Kim et al., 2003).

A small visual summary was created to illustrate how many columns were successfully matched to descriptive headers, accompanied by a bar chart showing variables with the highest missing values. Even simple visualisations such as these help contextualise the cleaning effort, revealing where information is sparse or inconsistently captured.

## **Unit 4 Artefact — Cleaning & Transformation Outputs**

The following artefacts were added to the GitHub repository:

- `mn.csv` — raw dataset  
- `mn_headers.csv` — header mapping file  
- `clean_mn.csv` — cleaned dataset  
- `matched_headers.csv` — successfully matched header pairs  
- `unmatched_headers.csv` — header acronyms without a match  
- `header_match.png` — bar chart showing matched/unmatched headers  
- `na_top15.png` — top 15 variables by missingness  
- `clean_mn.py` — Python script performing mapping, cleaning, and summary outputs

### Notes:
- Acronym headers were translated where possible.  
- Missing placeholders were consolidated.  
- Duplicate-row checks returned none.  
- Data types were inspected for anomalies.  
- Unmatched headers reflected metadata inconsistencies common in cross-country surveys.
